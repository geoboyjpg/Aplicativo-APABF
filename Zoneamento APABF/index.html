Sobre o Mapa

Este mapa interativo apresenta o zoneamento da Área de Proteção Ambiental da Baleia Franca (APABF), com as zonas definidas no Plano de Manejo da unidade.

Funcionalidades

  • Navegue pelo mapa usando zoom e arraste
  • Abra o controle de camadas para consultar a legenda das zonas
  • Clique sobre uma zona para ver suas informações
  • Use o botão "Centralizar" para ir até a sua posição

Contato

Para dúvidas ou sugestões, entre em contato:

apadabaleiafranca@icmbio.gov.br

Ajuda do Mapa

Cada cor do mapa representa um tipo de zona da APABF (uso restrito, conservação, manejo de recursos pesqueiros, produção rural, uso divergente, uso moderado, uso múltiplo, populacional e urbanizada).

  • Toque no ícone de camadas, no canto superior direito, para ver a legenda e ligar ou desligar camadas.
  • Toque em uma área colorida para abrir a janela com as informações da zona.
  • Use os botões + e - para aproximar ou afastar o mapa.
  • Use a barra inferior para navegar entre os mapas do aplicativo.

Precisa de ajuda para usar o mapa?

Este mapa apresenta o zoneamento da Área de Proteção Ambiental da Baleia Franca (APABF), com as zonas definidas no Plano de Manejo da unidade.

  • Utilize os botões + e − para aproximar ou afastar o mapa.
  • Use o botão de localização para centralizar o mapa na sua posição atual.
  • Acesse o controle de camadas no canto superior direito para visualizar a legenda e ligar ou desligar as zonas do mapa.
  • Escolha uma zona colorida para visualizar suas informações detalhadas.
  • Use a barra inferior para navegar entre os mapas do aplicativo.
