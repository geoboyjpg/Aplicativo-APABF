Informações

Sobre o Mapa

Este mapa interativo apresenta os instrumentos legais aplicáveis à Área de Proteção Ambiental da Baleia Franca (APABF), com destaque para as normas que regulam o uso de redes de emalhe.

Funcionalidades

  • Navegue pelo mapa usando zoom e arraste
  • Acesse a aba "Instrumentos Legais" na lateral para consultar e pesquisar os instrumentos legais
  • Use o botão de localizar da tabela para exibir a área de abrangência de cada norma
  • Clique sobre uma área do mapa para ver os detalhes do instrumento legal

Contato

Para dúvidas ou sugestões, entre em contato:

apadabaleiafranca@icmbio.gov.br

Ajuda do Mapa

A tabela reúne os instrumentos legais que incidem sobre a APABF e suas respectivas áreas de abrangência.

  • Toque na aba "Instrumentos Legais" para consultar e pesquisar os instrumentos legais.
  • Toque no botão de localizar de uma linha para exibir apenas a área daquela norma no mapa.
  • Use "Mostrar Todas as Camadas" para voltar à visualização completa.
  • Use a barra inferior para navegar entre os mapas do aplicativo.
